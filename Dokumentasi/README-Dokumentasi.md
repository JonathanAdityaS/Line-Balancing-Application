## Panduan gambar per subbab

- **a. Diagram Alir Prototype** → wajib pasang `gambar-diagram-alir-prototype.png`.
- **b. Spesifikasi HW/SW** → pakai **tabel**, bukan gambar.
- **c. Pengumpulan Kebutuhan** → `gambar-use-case-diagram.png` (sudah ada) + foto observasi (tambahkan sendiri bila ada).
- **d. Pembangunan Prototype** → screenshot prototype v1 (tambahkan sendiri) + arsitektur sebagai konteks.
- **e. Pengkodean Sistem** → screenshot struktur folder + `gambar-alur-crud.png`.
- **f. Pengujian Sistem** → screenshot Swagger + dashboard + tabel uji (tambahkan sendiri).
- **g. Evaluasi Sistem** → tabel rekap revisi + grafik bila ada (tambahkan sendiri).
- **h. Penggunaan Sistem** → screenshot halaman aplikasi + panduan pakai (tambahkan sendiri).

## Cara pakai di laporan

1. Salin isi `BAB-3-Metodologi-Prototype.md` ke BAB 3 laporan.
2. Sesuaikan nomor gambar/tabel dengan penomoran kampus.
3. Tambahkan screenshot asli aplikasi pada subbab d, f, dan h.
